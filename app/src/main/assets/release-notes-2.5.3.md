# Waypoint 2.5.3

This update removes the fixed 150 MiB download limit from Waypoint's in-app updater.

- After installing this version, future updates can be larger when your phone has enough free space. Waypoint still checks the complete download, checksum, app identity, version, and signing certificate.
- This release remains below the 150 MiB limit in older installed versions, so they can still update directly.
- The 2.5.2 Android dependency updates, all 38 worlds, map artwork, and driving features remain available. Android still asks before installing and keeps your saved places, quests, and settings on compatible updates.

Maps, search, and routes need an internet connection. Android Auto availability in a real vehicle still depends on Google’s trusted installation requirements.
