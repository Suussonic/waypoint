- The screenshot supplied for this page shows the same No. 13 position. Its unchanged full image is [`assets/evidence/upstar-profile-full-2026-11-07.png`](assets/evidence/upstar-profile-full-2026-11-07.png), SHA-256 `f4de103b4177d5214fdd3fd673f03f5c92dd2fbdc09d9139e9c3f606bd054dcd`.

- The [repository’s GitHub topics](https://api.github.com/repos/the-geeky-couldron/waypoint/topics) include `android-app` and `android-auto`, but not `android`. The [GitHub Android topic page](https://github.com/topics/android) is a repository directory with star, fork and update sorting; it does not publish Upstar’s rank.
