# Character navigation lines for all 38 maps

Creative script for Waypoint's 38 world themes. Each map has one selected character reference and 20 examples covering the same frequently used navigation events. The map names and inspirations follow [Map Worlds](../wiki/Map-Worlds.md).

## Recording and implementation rules

- These are original sample lines, not quotations from the games. Character names describe creative references; the voice modulation prompts specify original performances, not actor imitations.
- Words in square brackets are runtime placeholders supplied by the route engine. If a road name, distance, exit ordinal, or destination is unavailable, use the engine's valid shorter instruction rather than speaking the placeholder.
- Speak the maneuver, distance, and road name first. The character phrase is optional flavor and must be dropped for immediate turns, urgent rerouting, or any cue where it could delay the instruction.
- Keep music and effects below the spoken instruction. Put chimes, ambience, and other decorative sounds after the direction.
- DOS Atlas, Vector Command, 16-bit Quest, and Home Console are broad interface or genre themes. Their selected characters are representative references, not members of a canonical cast for those themes.
