THE ROAD SO FAR

Every public release.

A short guide to the changes that shaped each version. Download counts stay at the beginning and end of the journey, not on every release.

  1. 0.2.1

    Released 30 October 2026

    v0.2.1 · the first public build

    Waypoint’s first public GitHub-built Android release opened 27 game-inspired worlds to everyone, with manual in-app updates and a safer foundation for navigation.

    Release notes ↗
  2. 0.2.3

    Released 30 October 2026

    v0.2.3 · a clearer introduction

    New showcase artwork and a more useful README introduced the project, while personal spelling aliases stayed in private app preferences.

    Release notes ↗
  3. 1.0

    Released 2 November 2026

    v1.0.0 · the first stable release

    27 distinctive real-world map styles, place search and spoken routes arrived in the first stable release, alongside a redesigned introduction to the app.

    Release notes ↗
  4. 1.1

    Released 2 November 2026

    v1.1.0 · into the car

    Android Auto brought Waypoint’s selected world, route, turn cues and destination search onto the car display.

    Release notes ↗
  5. 1.5

    Released 4 November 2026

    v1.5.0 · voice that finds its way

    More reliable text-to-speech initialization made spoken turn instructions work with the voices already installed on a phone.

    Release notes ↗
  6. 2.0

    Released 5 November 2026

    v2.0.0 · 38 worlds and personal quests

    Waypoint grew to 38 worlds and added personal tasks, focus sessions, bicycle routes, place sharing and more ways to shape a journey.

    Release notes ↗
  7. 2.0.1

    Released 5 November 2026

    v2.0.1 · updates that remember

    Onboarding now stays complete after an update, coordinates can find more than one saved place, and What’s New covers every release you skipped.

    Release notes ↗
  8. 2.5

    Released 6 November 2026

    v2.5.0 · original cartography

    All 38 worlds received Waypoint-made map materials, place symbols and markers, while navigation cameras followed the selected road through turns.

    Release notes ↗
  9. 2.5.1

    Released 6 November 2026

    v2.5.1 · the updater gets through

    A download-size issue that blocked in-app updates from older versions was fixed, with all 38 worlds and new map artwork intact.

    Release notes ↗
  10. 2.5.2

    Released 6 November 2026

    v2.5.2 · a sturdier toolchain

    Android, map and networking dependencies were refreshed while keeping the APK small enough for the older in-app updater.

    Release notes ↗
  11. 2.5.3

    Released 6 November 2026

    v2.5.3 · bigger updates, still checked

    The updater stopped enforcing an old fixed download cap, while retaining checksum, package, version and signing-certificate verification.

    Release notes ↗
  12. 2.5.4

    Released 7 November 2026

    v2.5.4 · map icons made whole

    Damaged place icons across the worlds were repaired, Night City and Machine Atlas artwork was restored, and phone map controls gained clearer sizing and placement.

    Release notes ↗
  13. 2.6

    Released 9 November 2026

    v2.6.0 · speed limits and transit

    Phone guidance added posted speed-limit warnings, bus and transit trip planning, and a direct way to join the Waypoint Discord.

    Release notes ↗
  14. 2.6.5

    Released 12 November 2026

    v2.6.5 · steadier routes, more useful places

    Navigation settled through turns and at stops; downloaded regions gained open place names, alongside broader search and map rendering fixes.

    Release notes ↗
  15. 2.6.6

    Released 13 November 2026

    v2.6.6 · smoother, user-led map movement

    Low-memory devices reduced map-rendering work, and manual zoom or pan stopped snapping back to the current location.

    Release notes ↗
  16. 2.7

    Released 15 November 2026

    v2.7.0 · clearer maps, steadier guidance

    Place symbols now scale consistently across all 38 worlds, navigation keeps its selected camera pitch, and landscape guidance shows speed again.

    Release notes ↗
